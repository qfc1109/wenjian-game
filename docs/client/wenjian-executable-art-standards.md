# 问剑江湖可执行美术标准

## 1. 背景

首批概念图完成后，用户反馈不满意。项目经理与美术总监复盘后确认：首批图可以作为早期探索记录，但不应继续沿用“生成好看的武侠概念图”的路线。

下一轮美术工作改为定义可执行的游戏美术标准，优先服务 Unity 原型、角色规格、战斗可读性和 UI 信息层级。

## 2. 核心方向

用户已确认方向为：

- 明快清爽的像素武侠。
- 类似轻量动作肉鸽。
- 战斗读得很清楚。

三条硬标准：

- 风格：清晰像素风，不要写实厚涂伪像素。
- 气质：明快、古朴、有剑意，不要过暗、过脏、过西幻。
- 用途：每张图都必须服务游戏落地，例如角色尺寸、地块规格、战斗可读性、UI 信息层级。

## 4. Unity 原型约束

### 4.1 角色

- 原型阶段角色画布优先按 48x48。
- 实际身体高度建议 24-32 像素。
- 职业必须先靠剪影区分，再靠颜色和特效区分。
- 单帧站姿、移动方向和攻击起手要保持低信息量、强辨识。

### 4.2 场景

- Tilemap 原型优先按 32x32 地块。
- 可走区域、障碍区域、边界区域必须在视觉上清楚区分。
- 战斗中心区域要保留足够留白，避免竹子、石块、装饰遮挡敌我。
- 场景明度不应过低，角色和技能必须压得住背景。

### 4.3 技能特效

- 普攻拖尾短、亮度低，不遮挡角色。
- 小技能可使用青白、淡金、玉绿色，但范围必须清楚。
- 大招可以更亮，但不能让敌人、碰撞区和伤害区消失。
- 禁止西式魔法阵、黑暗符文、过度粒子爆炸。

### 4.4 HUD

- HUD 必须围绕屏幕边缘，不压住中央战斗区域。
- 血条、内力、技能栏、小地图、掉落提示需要有明确优先级。
- 美术语言使用宣纸、墨线、玉、铜、剑纹，不走暗黑 ARPG 重金属风。

## 5. 拒绝标准

出现以下情况的素材，不进入下一阶段拆分：

- 看起来像缩小后的厚涂插画，而不是清晰像素图。
- 画面整体过暗、过脏、过灰，战斗目标不清楚。
- 角色或怪物在 48x48/64x64 级别无法区分职业和攻击姿态。
- 地图装饰过多，中央战斗区域没有稳定走位空间。
- HUD 盖住玩家、敌人、技能范围或掉落信息。
- 武侠味不足，明显偏西幻、哥特、暗黑地牢或现代元素。
- 图片中出现可读文字、水印或与项目无关标识。

## 6. 下一步

1. 由项目经理组织用户评审第二轮 7 张标准图。
2. 通过后，冻结第一版美术执行标准。
3. 再进入 Unity `Proto_CombatField` 原型素材拆分：角色占位 Sprite、32x32 Tilemap、基础 VFX、HUD 占位组件。
4. 未通过时，不继续扩展素材数量，先收敛失败原因并修订提示词。
