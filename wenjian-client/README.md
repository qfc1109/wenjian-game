# wenjian-client

Unity 客户端目录。

第一阶段客户端目标：

- 验证像素风、俯视角、武侠即时动作的视觉方向。
- 建立 `Proto_CombatField` 灰盒原型。
- 验证 8 方向移动、Tilemap、Pixel Perfect 相机、普攻、剑气技能、HUD 和网络输入占位。

当前已完成：

- `ArtConcepts/`：首批概念美术素材。
- `ArtConcepts/round2-visual-standards/`：第二轮可执行美术标准素材。
- `Proto_CombatField/`：第一阶段 Unity 原型壳说明，用于后续验证 48x48 玩家、32x32 Tilemap、竹林测试场景、HUD 和后端 `RegionSnapshot` 展示。

后续 Unity 正式工程目录会在版本和原型任务确认后创建。当前 `Proto_CombatField/` 只作为原型壳和验收标准，不代表完整 Unity 工程已经创建。
