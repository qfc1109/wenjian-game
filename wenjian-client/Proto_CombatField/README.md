# Proto_CombatField

`Proto_CombatField` 是《问剑江湖》第一阶段 Unity 客户端原型壳，用于验证前后端最小链路是否能满足实际画面、输入和战斗可读性。

当前目录不是完整 Unity 工程，仅定义原型验收标准、资源引用和后续创建 Unity 场景时的约束。因此当前阶段还不能启动游戏试玩。

## 1. 原型目标

第一阶段只验证一条可见链路：

1. 客户端连接后端 WebSocket 网关。
2. 客户端发送登录请求。
3. 客户端发送进入竹林测试区域请求。
4. 后端返回区域快照。
5. 客户端显示玩家、训练敌人和竹林战斗场景。
6. 客户端发送一个技能意图。
7. 客户端展示服务端返回的技能事件或伤害事件。

## 2. 美术与尺度约束

- 玩家目标规格：48x48 sprite cell。
- 玩家实际身体高度：24-32 像素。
- 地块目标规格：32x32 Tilemap。
- 第一场景：竹林战斗场。
- 第一 HUD：生命、内力、技能槽、小地图或区域指示。
- 技能 VFX：短剑气、方向性清楚，不遮挡玩家、敌人和碰撞区域。

参考素材：

- `wenjian-client/ArtConcepts/round2-visual-standards/`
- `docs/client/wenjian-executable-art-standards.md`

## 3. 网络验收

第一条网络验收目标：

- 能展示后端 `RegionSnapshot` 或等价的进入区域响应。
- 玩家出生点使用配置表初始位置：`config/source/player_template.csv`。
- 第一测试区域使用区域 id `1001`。
- 客户端画面至少展示玩家自身和一个训练敌人。

## 4. 暂不实现

第一阶段不做以下内容：

- 正式角色序列帧。
- 完整背包、任务、聊天、商城。
- 完整 KCP 实时通道。
- 复杂随机肉鸽房间。
- 最终 UI 组件切图。

## 5. 后续任务

1. 创建 Unity 工程或场景目录。
2. 添加竹林测试 Tilemap。
3. 添加 48x48 玩家占位。
4. 添加训练敌人占位。
5. 添加最小 HUD。
6. 接入后端第一链路。
7. 验证 RegionSnapshot 展示和单技能事件展示。
