# Proto_CombatField ArtReference

本目录记录 `Proto_CombatField` 原型引用的美术标准，不直接复制或拆分最终 Unity 资源。

## 引用来源

- 第二轮可执行美术标准目录：`wenjian-client/ArtConcepts/round2-visual-standards/`
- 第二轮批量预览：`wenjian-client/ArtConcepts/round2-visual-standards/contact-sheet-round2.png`
- 可执行美术标准文档：`docs/client/wenjian-executable-art-standards.md`

## 原型使用方式

- 角色规格参考 `08-character-spec-standard.png`。
- 战斗场景参考 `09-combat-field-readability.png`。
- HUD 参考 `10-hud-readability-standard.png`。
- 技能特效参考 `11-skill-vfx-readability.png`。
- 敌人剪影参考 `12-enemy-silhouette-standard.png`。

## 约束

- 原型阶段优先验证 48x48 角色、32x32 地块和战斗可读性。
- 本目录不保存密钥、外部生成参数或未确认版权来源。
- 图片素材进入 Unity 前需要再次拆分为 Sprite、Tilemap、VFX 序列帧或 UI 组件。
