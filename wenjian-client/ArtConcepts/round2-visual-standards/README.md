# 问剑江湖第二轮可执行美术标准素材

## 1. 用途

本目录保存《问剑江湖》第二轮美术素材。与首批概念图不同，本轮目标不是“好看的大概念图”，而是建立可以指导 Unity 原型落地的可执行美术标准。

已确认方向：

- 明快清爽的像素武侠。
- 类似轻量动作肉鸽。
- 战斗读得很清楚。

硬标准：

- 风格：清晰像素风，不要写实厚涂伪像素。
- 气质：明快、古朴、有剑意，不要过暗、过脏、过西幻。
- 用途：每张图都必须服务游戏落地，比如角色尺寸、地块规格、战斗可读性、UI 信息层级。

## 4. 初步评估

本轮素材比首批更接近项目目标：

- 像素风更明确，减少了厚涂概念图倾向。
- 画面更明快，战斗目标、走位空间和 UI 边界更清楚。
- 角色、敌人、VFX、HUD、Tilemap 都更贴近 Unity 原型拆分需求。

仍需人工评审：

- 角色是否还需要进一步压缩到更严格的 48x48 规格。
- HUD 是否仍有暗黑 ARPG 味道，需要继续降低金属厚重感。
- 主城和秘境素材是否可以拆成稳定的 32x32 地块与可复用物件。
- 技能特效在真实战斗中是否过亮或覆盖碰撞信息。

## 5. 拒绝标准

后续素材如果出现以下问题，应直接退回重做：

- 伪像素、厚涂、写实渲染明显。
- 画面过暗、过脏、过灰。
- 角色、怪物或技能在小尺寸下不可读。
- 场景装饰压缩走位空间。
- UI 遮挡中央战斗区域。
- 偏西幻、暗黑地牢、现代元素或无关题材。
- 出现可读文字、水印或无关标识。
