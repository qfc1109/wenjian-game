## 4. 风格基准

关键词：

- 像素风
- 俯视角 / 2.5D 俯视
- 武侠江湖
- 山水卷轴感
- 即时动作肉鸽
- 明暗清晰的战斗可读性
- 古朴但不厚重
- 少量奇幻内力表现

颜色方向：

- 世界地图：淡墨、青绿山水、纸卷暖灰
- 主城小镇：暖木色、灯笼红、青瓦灰、布幡米白
- 野外区域：墨绿、土黄、湿石灰、深林绿
- 秘境区域：冷蓝、幽紫、暗金、少量血红
- UI 氛围：宣纸底、墨线边、铜件按钮、玉石和剑纹点缀

角色比例：

- 玩家角色建议头身比 1:2.5 到 1:3。
- 第一阶段 Unity 原型可先使用 48x48 画布，实际身体约 24-32 像素高。
- 普通怪物可先用 32x32 或 48x48，Boss 可放大到 64x64 或 96x96。

技能特效：

- 普攻使用低亮度短拖尾，避免遮挡角色。
- 小技能使用中亮度方向性特效，持续 0.2-0.6 秒。
- 大招可以更亮，但必须保留角色、敌人和伤害范围可读性。
- 剑气以青白、淡金为主，命中可用少量白光和像素颗粒。
